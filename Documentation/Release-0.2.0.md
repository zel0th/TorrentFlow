# TorrentFlow 0.2.0

- Крупные фильтры загрузок перенесены в верхнюю панель под инструментами.
- Инспектор размещён снизу; его высоту можно менять разделителем.
- Добавлены вкладки «Пиры» и «Логи».
- Для пиров отображаются адрес, страна по локальной IP-базе, клиент, готовность и скорости.
- В логах видны ошибки и важные события движка, трекеров и файловых операций; журнал ограничен по размеру.
- Иконка: белая основа, матовая оранжевая стрелка и синий лоток с небольшим стеклянным элементом.
- Дополнен сценарий удаления вместе с файлами через Корзину.
- Переработан переход magnet от получения метаданных к передаче данных с сохранением найденных соединений.

Проверки и измерения ресурсов описаны в Validation.md и Performance-0.2.0.md.
