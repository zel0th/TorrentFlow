# TorrentFlow 0.2.1

- В окне добавления можно переименовать отдельные файлы до начала загрузки. Расширение сохраняется при первоначальном выделении имени; доступен возврат исходного названия.
- Ускорен поиск метаданных magnet: параллельный опрос трекеров, сохранение DHT между запусками и более частое обновление окна ожидания.
- Убрано размытие выбранного верхнего фильтра; сохранены крупные шрифты 17/19 пт.
- В «Обзоре» прогресс занимает всю ширину, два блока сведений находятся ниже.
- Приоритет каждого файла меняется выпадающим списком в его строке.
- Во вкладке «Трекеры» можно добавлять адреса HTTP, HTTPS и UDP.
- У инспектора оставлен один заголовок. Первая видимая загрузка автоматически выбирается, в том числе после восстановления состояния.
- В настройках загрузок появилась опция предотвращения автоматического сна Mac во время активной загрузки. Окно настроек по-прежнему обходится без вертикальной прокрутки.

Методика, результаты и границы проверки: [Validation.md](Validation.md), [Performance-0.2.1.md](Performance-0.2.1.md).
