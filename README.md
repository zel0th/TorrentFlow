# TorrentFlow 0.2.0

Нативный BitTorrent-клиент для **macOS 27 и Apple silicon**. SwiftUI / AppKit, **libtorrent 2.1.2**, OpenSSL 4. Готовое приложение содержит движок и не требует Homebrew или Python.

![Иконка TorrentFlow](Design/Icon-Master.png)

## Загрузки

- Открывает `.torrent` и `magnet`, скачивает и раздаёт BitTorrent v1, v2 и hybrid.
- Перед каждой новой задачей показывает папку сохранения и дерево файлов. Можно исключить файлы и папки, выбрать низкий, обычный или высокий приоритет, добавить задачу на паузе.
- Для magnet сначала получает только метаданные. Содержимое не запрашивается до подтверждения. Найденные пиры и состояние трекеров сохраняются при переходе к загрузке.
- Поддерживает паузу, восстановление прогресса, проверку файлов, показ в Finder и изменение приоритетов после старта.
- Предлагает удаление только задачи либо задачи вместе с файлами через Корзину. Удаление файлов всегда требует отдельного подтверждения; общая папка загрузки целиком не удаляется.

## Интерфейс

Крупные фильтры **17/19 пт** расположены под панелью инструментов. Инспектор находится снизу и меняет высоту нативным разделителем.

Вкладки инспектора: **Обзор · Файлы · Трекеры · Пиры · Логи**. В пирах видны IP/порт, страна по IP, клиент, готовность и скорости. Страна определяется по встроенной локальной базе IPv4/IPv6; адреса не отправляются в онлайн-сервисы геолокации. Клиент отображается по данным протокола и может не сообщить своё название.

Логи содержат ошибки и важные сообщения libtorrent, трекеров, хранения и действий пользователя. Есть фильтр ошибок, просмотр и копирование полного сообщения. Журнал ограничен 2000 сообщениями и примерно 1 МиБ текста; он хранится в памяти текущего запуска.

Четыре вкладки настроек целиком помещаются в окне без вертикальной прокрутки. Есть светлое, тёмное и системное оформление, Liquid Glass и поддержка системных настроек контраста и прозрачности. Иконка — белая основа, матовая оранжевая стрелка и синий лоток с небольшим стеклянным бортиком.

## Сеть

DHT, PEX, LSD, UPnP/NAT-PMP, шифрование пиров, выбор входящего порта, лимит соединений, лимиты загрузки/отдачи, тихий режим и остановка раздачи при заданном рейтинге. Для private-торрентов libtorrent соблюдает ограничения протокола. Шифрование пиров не является VPN.

## Установка

Распакуйте ZIP готового приложения и перенесите `TorrentFlow.app` в «Программы». Используется локальная ad-hoc подпись; подпись Developer ID и нотариализация Apple не выполнены. При блокировке macOS предусмотрено разрешение открытия в «Системные настройки → Конфиденциальность и безопасность».

## Сборка из GitHub

Нужны **macOS 27**, Command Line Tools со Swift 6.4 или Xcode 27. Сторонние бинарные зависимости не включены в Git-историю. Для первой сборки установите CMake и OpenSSL через Homebrew, затем:

```sh
brew install cmake openssl
bash Scripts/bootstrap-engine.sh
python3 Scripts/build-geoip.py
bash Scripts/build-app.sh
```

`bootstrap-engine.sh` загружает закреплённые версии libtorrent/Boost, проверяет SHA-256 и создаёт статические библиотеки в `Vendor/`. Готовый каталог `Vendor` можно сохранять для следующих сборок. Генератор создаёт локальную базу стран `Resources/GeoIP.bin`. Она включена в готовое приложение; в Git хранится код генератора и описание источника. Если база уже создана локально, этот шаг можно пропустить.

Результат: `build/TorrentFlow.app` и ZIP в `build/releases/`. Проект можно открыть через `Package.swift` в Xcode.

## Проверки и ресурсы

```sh
bash Scripts/test-engine.sh
bash Scripts/test-magnet-discovery.sh
bash Scripts/test-geoip.sh
python3 Scripts/benchmark.py --app build/TorrentFlow.app
```

Тесты используют собственные синтетические данные, временные каталоги и локальный сид. Регрессия magnet проверяет поиск пира через HTTP-трекер **без `x.pe`**, получение метаданных без payload и последующую передачу выбранного содержимого. Для сетевых тестов нужны разрешённые loopback-сокеты.

Бенчмарк измеряет настоящий Release-процесс GUI: простой, передачу 256 МиБ по loopback с ограничением 8 МиБ/с и паузу после передачи. Сид и измеритель работают отдельными процессами. CPU рассчитывается по приросту пользовательского и системного времени с учётом Mach timebase; 100% означает одно занятое ядро. Отчёт содержит RSS, physical footprint и проверку SHA-256 результата.

Результаты и ограничения измерений: [Validation.md](Documentation/Validation.md), [Performance-0.2.0.md](Documentation/Performance-0.2.0.md). Контрольный прогон выполнен без взаимодействий с окном во время измерений. Предыдущий прогон с визуальной проверкой, включая краткий пик CPU, сохранён отдельно: [Performance-0.2.0-UI-observation.md](Documentation/Performance-0.2.0-UI-observation.md).

## Данные приложения

Resume-данные: `~/Library/Application Support/TorrentFlow/Resume`. Сохранение каждые 15 секунд, после команд и при штатном выходе. Настройки — UserDefaults. Тестовое переопределение состояния: `TORRENTFLOW_STATE_ROOT`.

В торрентах v1 кусок может пересекать границу выбранного и пропущенного файла. Соседние байты, нужные для проверки хеша, могут сохраняться во вспомогательном part-файле libtorrent. Приоритет означает предпочтение запросов, а не строгую последовательность загрузки.

## Границы версии

Не входят RSS, создание торрентов, поиск, веб-интерфейс, плагины, встроенный VPN и автообновление. Разные роутеры, VPN, публичные swarm под большой нагрузкой и все варианты файловых систем отдельно не тестировались. Страна по IP может отличаться от физического местоположения пира. Поддерживается Apple silicon; Intel-сборка не предоставляется.

Визуальные ориентиры — MKVStudio и MacKey. Иконка создана ImageGen. Приложение разработано с помощью OpenAI Codex. Лицензии и атрибуция libtorrent, Boost, OpenSSL и базы стран: [Documentation/Licenses](Documentation/Licenses).
