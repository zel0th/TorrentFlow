TorrentFlow

A native BitTorrent client for macOS 27 and Apple silicon. libtorrent 2.1.2 is included in the app.

Add a transfer

  1. Open a .torrent file with ⌘O or a magnet link with ⌘L. You can also drag a torrent file from Finder.
  2. For a magnet link, wait for the file list. Available peers are required. File contents are not downloaded until you confirm.
  3. Choose the destination folder. Select the files and folders you want, and set their high, normal or low priorities. “Do not download” excludes a file. Click the pencil beside a file to rename it; the extension is initially left outside the selection. The revert arrow restores the original name.
  4. Click “Start Download”, or turn off immediate start to add the transfer on pause.

Retrieving magnet metadata requires a network connection, even when the transfer will be added on pause.

Manage transfers

The large filters are below the toolbar. The inspector sits at the bottom; drag its divider to change its height. The Downloads menu provides pause and resume commands, file verification, Show in Finder and removal. Open the inspector with ⌥⌘I. In Files, use each row’s priority menu to change which files are downloaded. The Done column displays both a percentage and a background progress bar. In Trackers, “Add Trackers…” accepts one HTTP, HTTPS or UDP address per line.

Removing a transfer from the list keeps its files. “Remove with Files” moves that transfer’s files to Trash after confirmation. Progress is saved every 15 seconds, after major commands and on normal quit. Recent pieces may need to be checked again after a crash.

Priorities and skipped files

Priority affects the order of requests to peers but does not guarantee sequential downloading. In v1 torrents, a piece can span the boundary between a selected and a skipped file. Bytes needed to verify that boundary may be stored in libtorrent’s auxiliary part file; the skipped file itself remains excluded.

Peers and logs

Peers shows the address, country from a local IP database, remote client, completion and transfer speeds. IP addresses are not sent to an online geolocation service. Logs contains errors and important messages from the current session, with an errors-only filter and message copying. The log has a fixed size limit. Messages from libtorrent and remote peers may use their original language.

Settings

Open Settings with ⌘,. General, Downloads, Speed and Network fit in the window without vertical scrolling. General includes the interface language: Automatic, Русский or English. Automatic follows the supported languages in your macOS language preferences and falls back to English. Language changes update TorrentFlow’s interface immediately; system-owned panels and menu items follow macOS.

A speed limit or ratio limit of zero means unlimited. Quiet Mode replaces the normal download and upload limits with the lower limits configured in its own block. The turtle button switches it on or off. Quiet Mode limits network bandwidth; it does not pause transfers or mute sounds.

In Downloads, “Prevent Mac from sleeping while downloading” prevents automatic system sleep until active downloads are paused or completed. The display can still sleep. Manual sleep and closing the lid are controlled by macOS.

For private torrents, the engine respects restrictions on DHT, PEX and LSD. Peer encryption does not hide your IP address.

Version 0.2.2

Supports .torrent and magnet downloading and seeding, BitTorrent v1/v2/hybrid, file selection, renaming, priorities, resume data, speed limits, DHT/PEX/LSD, UPnP/NAT-PMP and peer encryption. Torrent creation, web UI, RSS, tracker search, plug-ins and a built-in VPN are not included.

The app uses a local ad-hoc signature. Apple Developer ID signing and notarization require developer credentials.
